# Security

This tool is for a user's own locally synchronized WeChat account. Do not use it to access another person's account, bypass remote authentication, or collect credentials.

Do not include real exports, local anchors, logs, databases, account IDs, group IDs, or machine paths in bug reports. Redact screenshots and reproduce parser issues with fictional fixtures.

The program is designed to keep validated database keys in process memory only and to avoid plaintext database files. If you find a path that logs or persists keys, or a way that plaintext data remains after a failed run, report it privately through GitHub Security Advisories rather than a public issue.
